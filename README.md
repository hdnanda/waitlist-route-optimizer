# Dynamic NLP Routing Engine Sandbox

This is a Vite + React application. Do **not** use VS Code's **Go Live** button:
Live Server serves files as-is and cannot compile the JSX in `src/main.jsx` or
resolve the React and Tailwind packages.

## Run it in VS Code

1. Open the integrated terminal in this folder.
2. Run `npm install` once.
3. Run `npm run dev`.
4. Open the `http://localhost:5173` URL that Vite prints in the terminal.

Alternatively, select **Terminal → Run Task → Start Dynamic NLP Sandbox** after
installing dependencies.

To make a production build, run `npm run build`; preview it with `npm run preview`.
